# Transform（转换）

OOMOL 平台上的基础数据转换模块集合。

## 概述

Transform 包为你的 OOMOL 工作流提供了在不同格式之间转换数据的基础构建模块。无论你是处理字符串、二进制数据还是 JSON 对象，这些模块都能帮助你在各种格式之间无缝转换数据。

## 使用场景

- **数据处理流程**：在处理文件或网络数据时，在文本和二进制格式之间转换
- **API 集成**：解析来自 Web 服务的 JSON 响应或为 API 请求格式化数据
- **文件操作**：使用不同的字符编码对文件进行编码和解码
- **数据格式化**：通过自定义缩进和字符编码控制 JSON 数据的显示方式

## 可用模块

### Encode String（编码字符串）

使用指定的字符编码将文本字符串转换为二进制数据。

**输入：**
- `string` - 要编码的文本字符串
- `encoding` - 要使用的字符编码格式（默认：UTF-8）

**输出：**
- `binary` - 编码后的二进制数据

**常见用途：**
- 为文件写入准备文本数据
- 在网络传输前转换字符串
- 处理不同的字符集（UTF-8、ASCII 等）

---

### Decode String（解码字符串）

将二进制数据转换回可读的文本字符串。

**输入：**
- `binary` - 要解码的二进制数据
- `encoding` - 字符编码格式（可选 - 如果未指定则自动检测）

**输出：**
- `string` - 解码后的文本字符串
- `encoding` - 检测到或使用的编码格式

**常见用途：**
- 将二进制文件内容读取为文本
- 处理接收到的网络数据
- 从不同编码格式转换数据

---

### Stringify JSON（字符串化 JSON）

将 JSON 对象转换为格式化的文本字符串。

**输入：**
- `json` - 要转换的 JSON 对象
- `indent` - 缩进的空格数（0 = 紧凑格式，>0 = 美化格式）
- `ensure_ascii` - 是否转义非 ASCII 字符（用于兼容性）

**输出：**
- `string` - 格式化后的 JSON 字符串

**常见用途：**
- 准备用于文件存储的 JSON 数据
- 格式化 JSON 以便显示或记录
- 创建 API 请求负载
- 控制 JSON 输出格式

---

### Parse JSON（解析 JSON）

将 JSON 格式的文本字符串转换为可用的 JSON 对象。

**输入：**
- `string` - 要解析的 JSON 格式文本

**输出：**
- `json` - 解析后的 JSON 对象

**常见用途：**
- 读取 JSON 配置文件
- 处理 API 响应
- 将 JSON 字符串转换为结构化数据

---

### Extract Object（提取对象）

将 JSON 对象拆分为单独的字段以便分别处理。

**输入：**
- `object` - 要从中提取字段的 JSON 对象
- `disable_additional_properties` - 启用时，仅提取指定的字段，如果存在额外字段则报告错误

**输出：**
- 基于对象字段的动态输出

**常见用途：**
- 将复杂对象分解为单独的组件
- 从 API 响应中提取特定数据
- 验证对象结构

## 示例工作流

### Encode & Decode（编码与解码）
一个简单的工作流，演示如何将字符串编码为二进制数据并将其解码回文本。这对于理解文本数据如何以二进制格式存储和传输非常有用。

### Parse & Stringify（解析与字符串化）
一个将 JSON 对象转换为格式化字符串并将其转换回来的工作流。非常适合学习如何控制 JSON 格式化和处理结构化数据。

## 快速开始

1. 将 Transform 包添加到你的 OOMOL 项目
2. 将所需的模块拖放到你的工作流中
3. 连接模块以创建数据转换流程
4. 根据需要配置编码或格式化选项
